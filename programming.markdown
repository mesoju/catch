# YOU HAVE ARRIVED AT: PROGRAMMING

Welcome to the Programming page!<br>The Programming sub-team is arguably one of FRC's **hardest** specialty with extensive documentation and research required to operate the robot and allow it to do wonders. Java by itself is an intermediate language with some abstract concepts, and the entire *[WPILib](https://wpilib.org/) + [FRC](https://docs.wpilib.org/en/stable/index.html)* software suite makes programming all the more daunting to handle. *CATCH* was first piloted to address these problems by creating short-intermediate videos and articles that guide you in understanding the FRC ecosystem for programming, ***you'll do great!***
